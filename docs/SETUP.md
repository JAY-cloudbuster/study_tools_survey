# Project Setup

## Prerequisites
- Python 3.8+
- PostgreSQL 13+
- pip package manager

## Installation
```bash
# Clone the repository
git clone https://github.com/JAY-cloudbuster/study_tools_survey.git

# Install dependencies
cd backend
pip install -r requirements.txt

# Set up environment variables
cp .env.example .env
```

## Running the Pipeline
```bash
python run_pipeline.py
```
